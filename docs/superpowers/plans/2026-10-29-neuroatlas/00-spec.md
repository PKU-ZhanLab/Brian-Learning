## 用户目标与本轮授权

面向科研人员，优先支持脑区定位、图谱比较和文献证据追溯。覆盖 2026-10-29 两轮审查中所有已提出的修正、能力补充和待验证问题。当前请求是完整记录并编写计划；不在本轮实施应用改动、安装依赖或部署网站。

“成为领先平台”用可完成、可核查、可复现的研究任务衡量，不用书目数量、模型数量或主观排名代替。评价主线为：输入坐标/选择分区/导入影像 → 确认空间和身份 → 比较结果 → 返回具体原文依据 → 保存并恢复同一研究现场。

## 固定约束

- 沿用 React 19、Three.js、Vite、Node 的现有技术基础。新测试依赖仅在实际执行相应任务时加入项目开发依赖；不在规划阶段安装。
- 需要 Python 时先检查对应 conda 环境；优先使用已存在且适合任务的环境。不得向默认环境临时装包；创建环境和新增依赖必须明确记录。
- 保留 DK/AAL/AAL3 的共用主脑形、切换视角，以及原始 Colin27 T1 三视图。原生与目标空间分开；不复活已退出当前界面的脊髓主流程。
- 不用模糊名称证明同一区域，不把灰质、白质束、概念区域或功能 ROI 混为一类。每个真实标签都可选；没有依据的映射明确未关联。
- 不把未明确模板的 MNI 坐标直接作为 NLin6Asym 坐标；重采样不冒充配准；1 mm 输出不冒充 1 mm 定位精度。
- 皮层标签保持离散 ID；不通过平均标签号、随意邻近填补或补点来制造覆盖。
- 项目导入失败不得改变原项目；打开与合并分开；导出不得无提示包含其他项目资产。
- 本地影像、笔记、自由文本和私有证据不得进入公开视图链接。默认不引入账号、云同步、遥测或第三方上传。
- 兼容读取现有 project/view/evidence v1；不能补造历史文件里没有的来源、空间或人工审阅信息。迁移保留原件并标注缺失。
- 动物、背景、侧化、直接测量与对当前目标区域的支持分别表达；不将 AI 辅助核对标为人工认证。
- 文献来源保存原文版本、位置、最小必要且可合法留存的证据及哈希；不能以“证据存档”为由批量再分发受限全文或图像。
- 保持中英文能力、现有图例、方向标、缩放/标准视角、命名视图、取消计算与错误/空结果提示。界面主要说明面向用户，不堆积内部实现历史。

## 范围与默认决策

### 必须修正

精确标签身份、查询状态失效、项目事务与资产归属、导入导出一致性、证据关系语义、检索完整性、来源与结果的保存恢复，以及审查指出的草稿、撤销、A/B 交接、比较篮、弹窗、键盘、窄屏和阅读障碍。

### 必须补齐的科研流程

精确坐标入口、多图谱归属、可选 ROI 网格与损失报告、完整结果来源清单、独立证据包、原始统计图/ROI 的来源链接、至少三个端到端科研验收案例。先形成完整且有来源的专题结果集，再扩大覆盖；不承诺任意数量即代表质量。

### 先验证再决定

全脑/小核团配准精度、替代脑干/小脑几何分段的新数据源、长内容裁切、低配设备性能、触屏/读屏器、成熟影像查看器的可替代性，以及定量证据评分/元分析方法。每项都在 backlog 中有任务，不以“以后再说”消失；未验证结论不按确定缺陷处理。

保留浅绿色视觉基础。建议基线为正文 14–16 px、辅助文字 12–13 px、坐标 13–14 px，普通文本对比至少 4.5:1；最终浏览器计算样式和可读性是验收依据。分类色、选中色、A/B/重叠色和证据状态分别定义。视觉原型及科研专题为实施时的方案选择，不冒充用户已经指定具体色值或专题。

## 共用契约与责任

以下为新增接口设计，当前版本并未具备。G0 在 `src/lib/research-contracts.js` 建立唯一文档化定义，子任务引用它；禁止同名字段在不同模块含义不同。

| 契约 | 字段及语义 | 实现责任 |
|---|---|---|
| `AtlasRegionRef` | `atlasId, atlasVersion, labelId, hemisphere, spaceId`；原图谱标签身份，不等同于目录概念。版本为明确版本或内容指纹。 | S1；S2 接入选择 |
| `AssetIdentity` | `id, version, sha256, spaceId`；具体输入或派生资产的身份。`spaceId` 为 `string|null`，未知空间为 null；仍可保留字节身份，但不能获得共同空间比较资格。 | G0 定义；S5/W6/E4 消费 |
| `QueryContext` | `atlasId, atlasVersion, coordinate, method, requestId`；一次坐标/表面查询上下文，结果只能回到同一请求。 | S3 |
| `ComputationManifest` | `appVersion, algorithmVersion, inputs, transforms, sourceGrids, targetGrid, interpolation, thresholds, labelSets`；inputs 为 AssetIdentity 列表，transforms 保留 `id,sha256`。 | S5 实现 `computation-manifest.js`；W6 保存恢复 |
| `ResultLayer` | `layerId, resultId, coordinateIds, sourceReferenceId, spaceId, visible, style`；来源可追踪的结果显示层。 | W5 实现 `result-layers.js`；X4 展示 |
| `brain-evidence-v2` | 书目、阅读记录、实验、结果、位置、claims、mappings、来源资产、审阅事件、关系及版本。保持原物种、原标签和目标关联分离。 | E2 唯一 schema/迁移；W2/W6 消费 |

S3 统一图谱/清单的资源状态和请求世代，X8 展示状态/重试；不要分别在 App、Scene、Slices 再造互不相通的错误状态。

W2 的权威持久化 envelope 只放笔记、证据、视图及受限草稿；影像继续使用会话资产与完整项目文件，不能把几百 MiB 二进制放入 localStorage。X5 的 `DraftRecord={id,projectId,kind,recordId,payload,updatedAt}` 保留未完成录入，单条 payload 上限 50,000 UTF-8 字节，最多 30 条，草稿总 JSON 上限 1 MiB；超限保留当前编辑并显示未保存，不能静默截断。项目 v2 可包含本项目草稿，v1 迁移默认空列表；草稿不进公共链接。若后续采用 IndexedDB，需另验证事务、配额及迁移，不改变本计划的失败零覆盖约束。

## 共同测试与验收规则

- 业务回归优先沿用 `node:test`；测试验证外部行为和真实数据不变量，不为纯样式变更制造实现镜像测试。
- G0 统一建立 `tests/e2e/*.spec.mjs`、`playwright.config.mjs` 与 `npm run test:e2e -- <path>`。不以 `npx` 的隐式下载解决缺失运行器。
- CI 浏览器测试只在依赖和执行权限明确的环境运行；当前桌面交互使用允许的 CUA 工具。没有可用浏览器时可以继续独立工作，但相关验收必须保持未完成。
- 审查 probes 有固定旧版本和旧错误预期；作为基线复现材料，不直接搬为修复后的绿灯测试。新测试断言正确的新行为。
- 每个任务做针对性验证和独立提交；集成阶段执行全量检查、公开构建及真实场景，不因已经通过而无条件重复全部测试。
- 测试宽度/视口：390、650、768 CSS px；1366×768、1440×900、1920×1080；桌面 200% 缩放。全部核心控制可达，长内容可滚动阅读；不要求同一布局硬塞所有屏幕。
- 配准与来源人工复核必须有真实审阅者、日期、范围和意见；缺人审时保留探索性/AI 辅助标签，相关“经人工审定”目标不完成。
- 公共发布以已验证源提交为唯一来源，数据清单和网页产物可追溯，可回退；实际推送仍属于执行阶段而非本轮规划。
