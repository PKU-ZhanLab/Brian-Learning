# 教学内容与引用

目录包含188个可检索结构：68个分侧DK皮层区、22个皮层下条目、3个脑干部位、3个小脑条目、5个脑室结构、23个纤维束条目、24个分侧颅神经、31个脊髓节段、7个脊髓灰白质/角条目和2个血管示意。

每条知识卡分别展示解剖、生理功能、认知、可选临床信息，并提供可展开的“依据与适用范围”。区域相关、系统或网络、教材证据分别标记；没有专门来源的字段明确提示待补。

## 教学解释

- DK脑回、AAL宏观区、BA细胞构筑区和功能影像定位使用不同标准，不能直接等同。几何边界来自数据，不依据功能描述绘制。
- 电刺激、动物单细胞、人体fMRI、损伤、干预及综述分别分类。研究涉及某个亚区，不证明整个宏观脑回功能均一。
- 功能网络筛选是相关结构集合；同一区域可参与多个网络。
- PAM50直化脊髓与脑模板保持坐标隔离。脊髓节段不等于同名椎骨；大多数颅神经脑外部分属于周围神经系统。
- BA1–52完整保留编号检索，缺失数据不制造边界；组织学子集与历史映射分别阅读。
- 临床内容默认关闭；常见表现受损伤侧别、范围、连接与个体差异影响。
