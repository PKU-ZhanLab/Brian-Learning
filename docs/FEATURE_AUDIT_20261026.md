# 功能核查 · 2026-10-26

当前目标版本：3.0.2。依据公开构建的数据清单、实际文件、实现代码及桌面 Edge 操作核查。这里区分“已实现但有范围限制”“未实现”和“尚未充分验证”，不以构建成功代替功能完成。

## 本次处理

- 从查看器、结构目录、搜索、教学预设和文献定位按钮中移除脊髓；当前显示目录为 150 个脑结构。“全中枢系统”改为“全脑概览”，“脑干与脊髓”改为“脑干与小脑”。查看器不再请求 PAM50。历史资料和已有批注仍可保留、导出。
- AAL、AAL3 和旧版 BA 标为“暂不可用”并禁选；旧链接请求这些图谱时返回 DK，并显示提示。没有把元数据说明当作可显示的模型。
- 补齐普通 MRI 切片的图谱彩色叠加。此前只有灰度图和交点标签，JHU 分区没有显示在切片上。
- 选择 Harvard–Oxford 自动打开深部结构和切片；选择 JHU 自动打开白质标签切片。页面明确区分 JHU 体素标签与 HCP1065 纤维流线。

## 八个菜单图谱的实际状态

标签数按实际二进制数据中的非零值统计，不把背景值或只有名字的条目算成可显示数据。

| 图谱 | 数据与显示状态 | 仍有限制 |
|---|---|---|
| DK | 68 个标签；配套皮层曲面、顶点分区、体素和切片可用 | 脑回分区不等同于精细功能区 |
| Harvard–Oxford | 21 个标签；当前接入皮层下版本，深部结构及切片可用 | 不是完整 HO 皮层图谱；大脑灰质/白质等整体标签不能解释成细分皮层区 |
| JHU ICBM-DTI-81 | 48 个非零白质标签；彩色切片、坐标查询和 ROI 计算可用 | 不是皮层分区，也不是纤维追踪；三维单标签边界需从 ROI 面板选择 |
| BA · FSL 历史标签 | 42 个实际标签；体素、切片、皮层采样颜色可用 | 历史数字化与已发表仿射近似；不是完整、精确的现代 BA 边界，不能把表面空白区域补成虚构分区 |
| BA · Jülich 组织学子集 | 22 个侧别/亚区标签，覆盖 9 个 BA 编号；体素与切片可用 | 只是子集，不覆盖 BA1–52；当前为固定阈值的最大概率标签 |
| AAL | 仅目录及来源；公开包没有体积文件，空间对应也未核验 | 尚不能显示或比较；仍需落实公开分发和空间处理 |
| AAL3 | 同上 | 尚不能显示或比较，小核团不能靠近似坐标代替真实标签 |
| BA · BrainNet 旧版 | 仅历史目录及来源，未核验与主模板的对应 | 暂停显示；已有 FSL 历史标签作为另一来源，二者不能混称同一图谱 |

图谱选择目前仍共用固定宏观结构目录，**尚未实现随图谱切换的完整标签树，以及各图谱全部标签的一键三维分区浏览**。ROI 面板可以选择实际标签；这不等同于上述完整浏览能力。

## 其他功能与缺口

| 功能 | 已有内容 | 尚未完成或不支持 |
|---|---|---|
| 脑区 ↔ 文献 | 双向阅读关联、主题/模态筛选、最多三篇并列阅读；115 篇来源，当前脑结构有效阅读关联 433 条 | 不是实时文献数据库，没有自动导入论文或自动抽取结果 |
| 文献精确定位 | 可高亮关联宏观结构，显示定位依据 | **已核验实验坐标为 0**；没有论文激活点、统计图或实验 ROI 掩模在三维中的精确映射 |
| 结果图 | 4 篇来源共有 6 个独立图链接 | 多数论文没有逐图整理；没有站内图像面板和图中区域到模型的精确对应 |
| 模态覆盖 | fMRI 19 篇、MEG 2 篇、EEG 1 篇、iEEG 3 篇、单单元 6 篇；一篇可多标签 | 覆盖明显不均衡，筛选器存在不表示该模态文献齐全 |
| 结论异同 | 3 组整理的研究讨论，论文结果/设计/限制并列阅读 | 没有自动证据综合、效应量汇总、质量分级或系统综述 |
| ROI 重叠 | 两个内置图谱各选一个实际标签；交集、并集、Dice/Jaccard、独占区、透明度、切片和 CSV | 不支持用户 NIfTI/统计图导入、多标签组合 ROI、概率图重叠、ROI 掩模导出或项目保存 |
| 模板对齐 | 使用已有模板、已发表映射及项目已有变换；计算时按声明仿射采样 | 没有通用自动非线性配准；重采样不能消除模板差异，名称相似也不是严格一一对应 |
| 真实解剖覆盖 | DK 配套表面、HO 大结构、HCP1065 部分通路 | 下丘脑、丘脑底核、黑质、红核尚无独立实测几何；12 对颅神经中仅 5 对有群体追踪估计；其他颅神经和脑血管仍有示意条目 |
| 脑干/小脑细分 | 整体外表面来自真实标签 | 脑干三部分及小脑中线带为几何教学切分，尚无独立精细分区验证 |
| 保存与分享 | 浏览器批注 JSON、PNG、文献导出；链接保存语言/图谱/所选结构/工作区 | 链接不恢复相机、ROI 选择、透明度或筛选条件；没有账户同步和完整工作区存档 |
| 教学 | 名称/功能选择题，当前会话计分 | 没有持久学习进度、题库管理或教师任务分发；题目和初始视角尚未逐题人工审定，内侧区域可能需旋转查看 |
| 兼容与性能 | 桌面浏览器可运行，模型按当前数据取景 | 手机触控、Safari/Firefox、离线故障恢复尚未全面验证；初始脚本较大，首屏加载仍有优化空间 |

## 验证与优先级

新切片叠加回归测试在修复前因没有颜色而失败；修复后通过，同时检查未验证空间不得叠加、背景保持不变和纯 MRI 调用保持灰度。现有 ROI/数据检查也继续保留。自动检查中的 188 个结构包含历史脊髓资料，不代表当前界面仍显示 188 个结构。

浏览器逐项检查 DK、HO、JHU、FSL 历史 BA 和 Jülich 子集的实际显示；AAL、AAL3、旧版 BA 不可选。更多实测结果记入 [验证记录](VALIDATION.md)。

建议下一步先完成 **AAL/AAL3 的合法可分发数据与空间核验、按图谱生成完整标签目录和单区三维显示**；再处理 **自定义 ROI 导入/保存、论文结果坐标和结果图整理**。这些工作尚未在本次自动补齐。
