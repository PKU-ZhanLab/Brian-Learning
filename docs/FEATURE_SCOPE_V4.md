# 功能范围 · 4.0

NeuroAtlas 是脑结构、分区与论文结论的对应工具。无账户、云端同步或服务器保存个人文件。脊髓已从活动界面移除。

## 已实现

- 完整图谱标签浏览：读取实际体素标签，支持搜索、多选、单区三维边界、原生空间独立浏览、透明度、图像保存。概览降采样遗漏的小标签会提示单独查看。
- AAL 的 116 个标签和 AAL3 的 166 个标签已接入。原生版本与 FSL MNI152NLin6Asym 配准估计版本分别提供，不能混称作者官方配准。AAL3 以 1 mm 网格保存全部标签；这不是 1 mm 配准精度的承诺。
- ROI：导入三维 NIfTI/NIfTI gzip、标签表、二值掩膜、统计图与概率图；多个标签并集、阈值与正负尾选择；Dice、Jaccard、覆盖比例、概率权重重叠；导出 CSV 和 A/B/交集/并集 NIfTI。
- 论文：118 篇内置文献；按脑区/主题/方法筛选、题录查询、本地编辑和 JSON 导入导出、结构化结果比较、关系注释和原文图入口。首批3篇论文提供4条结构化结果、8个有来源定位的坐标，均保留原文的 MNI-unspecified 身份，只在独立坐标视图显示。
- 本地保存：命名视图、完整项目文件，保存相机、透明度、切片、ROI参数、图谱浏览、论文筛选、批注和导入影像。命名视图不保存影像二进制，刷新后需项目文件恢复自定义数据。
- 视图链接：保存可公开重建的内置视图参数；自定义影像、私人论文编号和自由输入文字不会随链接发送。含私人数据的完整状态通过项目文件分享。

## 数据和验证边界

- 旧 BrainNet BA 未确认精确配对 T1 和可公开重分发依据，仍不可内置叠加。可导入自己的原始标签在独立空间查看；如需比较，必须取得匹配 T1、落实许可，并执行和检查配准。见 [配准操作](REGISTRATION.md) 与 [AAL来源和配准](AAL_INTEGRATION.md)。
- 部分颅神经、血管和细核团仍缺少独立来源几何。完整分区浏览不会把宏观目录中的示意结构自动升级为实测分割；AAL3 只涵盖其自身定义的核团。
- 118篇文献不等于118篇完整结果提取；当前8个坐标不具有确切 FSL 模板身份。自动和AI来源检查不等于人工专家复核。
- 4.0的算法、文件往返、格式校验和构建通过自动检查。本地浏览器已实际显示完整DK分区、论文结果字段和独立坐标；最终文件选择/完整项目恢复、移动端和全部新图谱的视觉验收尚未完成。
- 浏览器自动化在Windows地址识别检查处停止。未绕过该限制；不能把自动测试或HTTP校验当作上述界面验收。

操作详见 [使用指南](USER_GUIDE.md)、[ROI](ROI_WORKFLOW.md) 和 [论文结果](RESULTS_WORKFLOW.md)。
