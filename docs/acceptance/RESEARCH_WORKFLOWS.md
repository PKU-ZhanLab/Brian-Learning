# 三个科研流程 / Three research workflows

当前状态：各模块已有软件检查及固定版本 CUA 片段；下列完整新源组合尚未实际运行。G1 authored five isolated CI cases in research-journeys.spec.mjs/project-recovery.spec.mjs; discovery is not execution. 独立科研参与者、耗时、成功率与困难记录均为 null / pending-review。不能把三个编写案例称为三个已经完成的科研使用实验。

## 1 · 来源坐标 → 图谱 → 原文

从 Axelrod 2015 右 FFA 结果记录进入：原始均值 [39,-52,-16] mm，空间 MNI-unspecified；保存 DOI、结果版本、来源摘录位置和哈希。当前没有足以把该坐标直接当作 NLin6Asym 的依据。坐标输入保留原参考，模板图谱归属保持阻止/未知；不能为了完成旅程改名参考空间。

另用明确标为合成的 NLin6Asym 点 [5,-9,-4] 检查 DK / 配准 AAL3 查询与切换。它用于软件空间行为检验，与论文坐标分开；不产生新的论文定位主张。返回同一 Axelrod 结果、原文 DOI 和最小摘录，导出单篇证据包；独立解析闭包应包括统计、两侧位置、claims/limitations/source artifact及审阅范围。完整项目在第二空存储会话选取重开，再返回相同论文/结果，确认未知参考仍未升级。

可用实际证据：[E5 alias/re-export receipt](evidence/receipts/e5-cua--alias-fixed-receipt.json) 在8f7b6f1证明独立包/哈希和冲突零覆盖；当前 [E6 source audit](evidence/receipts/evidence-acceptance--topic-audit.json)记录4材料/8坐标/174 anchors，未将其改成直接叠加。新固定结果页与完整旅程 UI 为 not-run，真实科学来源→模板归属仍 pending-review。

## 2 · 两图谱标签组 → A/B → 比较

选择 DK 的一组真实标签与配准 AAL3 的一组标签，通过选择篮完整交给 A/B，保留另一侧参数。记录 AtlasRegionRef（图谱/版本/离散 ID/半球/空间），选择1或2 mm共同网格；逐标签检查源/目标体素、消失与未出现标签，确认损失后计算。导出 CSV/来源 JSON/NIfTI，应携带输入哈希、变换链、源网格、目标网格、阈值/尾部、算法和应用版本；无源输入不能据数值画新结果。

保存项目，在第二空存储会话通过文件选择恢复。检查 A/B 多选、显示、采样报告和原始历史，不触发自动计算；返回来源控制/并排来源视图。显式重算另存 recomputedSnapshot，原 roiSnapshot不覆盖。独立解释应足以确认使用哪一资产、哪组标签和哪一输出网格；Dice/Jaccard只描述二值空间重叠，不证明功能相同。

实际回归案例：[S4下载](evidence/receipts/s4-cua--download-verification.json)在共享模板1 mm的AAL3-134为7个体素，2 mm消失需确认；[W6往返](evidence/receipts/w6-cua--receipt.json)在a30cc08证明原7、重算0并存，恢复不调用worker、原始/重算ID不同。历史原生 Colin27 标签134为8个1 mm³体素，这是另一来源资产/阶段，不曾被覆盖。新两图谱完整旅程 not-run；显示/数值不等于解剖人审。

## 3 · 影像 → 声明/阈值 → 损失 → 导出与恢复

使用合成 NIfTI（两个体素，标量3/0，已知1 mm affine）；每个新文件重新声明 statistic、精确参考、来源、已对齐确认与阈值2.5/尾部。另以未验证/native声明重复边界检查应阻止模板比较。导入可取消、同文件可重试，失败不登记半成品。AAL3-134作A、合成图作B，报告1个阈上源体素及目标采样损失，保留原始文件身份与派生解码身份。

导出来源 JSON与掩膜/CSV，再导出完整项目（不是公开视图或PNG）。在第二会话重开文件，逐值核对影像、affine、原始源哈希、阈值、历史指标和结果图层；通过资产/来源信息返回原文件声明。删除/排除输入后保留历史检查但禁重算。公开链接不携带影像、私有笔记、自由文本、草稿或整组私有并排状态。

已有实际证据：[W6本地/v1](evidence/receipts/w6-cua--local-legacy-receipt.json)记录真实选择、计算、下载、重开、缺输入与v1迁移；[X8失败重试](evidence/receipts/x8-cua--single-atlas-retry-receipt.json)保留全部研究字段；[X9取消](evidence/receipts/x9-cua--near-limit-cancel-receipt.json)保留旧资产、无半成品，[同文件重试](evidence/receipts/x9-cua--near-limit-retry-receipt.json)校验64m值和源身份。这是任务版本观察，新统计图完整旅程 not-run；临床/低端设备性能和科学案例闭环 pending-review。
