# NeuroAtlas · 神经解剖与研究证据工作台

[English](README.en.md) · [使用指南](docs/USER_GUIDE.md)

面向神经科学与医学教学的双语三维工作台：从解剖结构查研究文献，再从论文回到相关脑区，并比较图谱 ROI 的实际空间重叠。

**在线地址（GitHub Pages 部署入口）：[NeuroAtlas](https://pku-zhanlab.github.io/Brian-Learning/)**

## 从这里开始

1. 用右上角 **中文 / EN** 一键切换界面和知识内容。
2. 在模型或目录中选择结构，阅读解剖、生理、认知与临床关联；展开“依据与适用范围”查看来源和限制。
3. 点击 **按脑区查文献**，或进入 **文献工作台** 按主题、方法、作者、DOI 检索。打开论文可定位关联脑区，并列比较最多三篇研究。
4. 进入 **ROI 对比**，选择两个允许比较的实际图谱标签，计算交集、独占区域、Dice 和 Jaccard；调节透明度并用切片核对内部重叠。

当前包含 **188 个结构、115 篇来源、21 个主题、18 类方法、3 组研究讨论和 6 个已核验原文图链接**。图链接打开原出版来源。文献关联用于阅读与定位相关结构，精确实验坐标须另有可核验的空间依据。

批注保存在当前浏览器，可导入、导出；视图可导出 PNG，文献可导出 BibTeX 或 GB/T 7714。**分享视图**保存语言、图谱、所选结构和工作区模式，相机位置与批注需另行保存。

## 数据范围

- **脑内参考**：FSL MNI152NLin6Asym。DK68 的曲面和标签来自同源重建；31 个 HCP1065 通路 / 颅神经条目使用本项目估计的模板变换。
- **ROI 对比**：在共同 2 mm 网格上按已有仿射最近邻采样实际二值标签掩模。这一步不估计新的解剖配准；当前使用内置图谱标签，不提供任意 NIfTI 导入。
- **脊髓**：公开版按需从固定版本的官方 GitHub 源加载 PAM50，由浏览器 Worker 生成 0.5 mm 体素边界表面。网站不镜像该数据。PAM50 保持独立、直化的原生参考，不表示正常脊髓曲率或与脑统一配准的人体模板。
- **未对齐图谱**：公开版保留 AAL、AAL3 和旧版 BA 的目录与来源说明，不提供其体积叠加或重叠计算。未覆盖结构仍可阅读知识条目，教学示意默认关闭。

功能区、脑回、BA、病灶和动物记录部位有不同定义。重叠指标不代表功能相同，文献题录核验也不等于逐篇全文审定或临床认证。详见[使用指南](docs/USER_GUIDE.md)、[文献范围](docs/LITERATURE_RESEARCH.md)、[逐区证据](docs/EVIDENCE_COVERAGE.md)和[空间说明](docs/SPACE_ALIGNMENT.md)。

## 本地运行

安装 Node.js 后，在项目目录运行：

```sh
npm ci
npm run check
npm run build
npm run preview
```

打开终端显示的地址。开发时可用 `npm run dev`。运行网页无需 Python；PAM50 首次按需加载需要能够访问官方数据源。

GitHub Pages 公开包使用：

```sh
npm run build:public
```

此构建使用 `/Brian-Learning/` 部署路径及公开数据打包规则。普通本地构建与公开包的数据范围有所不同。
