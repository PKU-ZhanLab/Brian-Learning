# NeuroAtlas · 神经解剖与研究证据工作台

[English](README.en.md) · [使用指南](docs/USER_GUIDE.md) · [结果整理流程](docs/RESULTS_WORKFLOW.md)

连接三维脑结构、图谱分区与论文结论的双语研究工作台。可查看实际图谱标签，比较 ROI 与统计图，整理带来源的论文结果，并用本地项目文件保存工作。

**在线入口：[NeuroAtlas](https://pku-zhanlab.github.io/Brian-Learning/)** · 本文对应 v4 工作流，在线版本以页面标识为准。

## 开始使用

1. **解剖探索 / 切片工作台**：选择结构，查看解剖、功能与研究依据；在三维模型与三正交切片之间定位。
2. **图谱分区**：浏览实际体积中的全部标签，搜索、单选或组合显示。原生空间图谱在独立视图中呈现；单选分区显示原始体素边界，概览可使用采样显示。
3. **文献工作台**：从脑区反查论文，按主题与模态筛选；在线检索 DOI / 标题，编辑结构化结果、坐标出处、结果图和研究间关系。
4. **ROI 对比**：导入本地 NIfTI 标签、掩膜、概率图或统计图，设置标签并集、阈值与方向，计算重叠并导出 CSV 和 NIfTI 掩膜。
5. **项目与视图**：保存命名视图、导出完整项目、打开项目文件，或复制可公开重建的视图链接。

当前知识目录包含 **150 个宏观结构、118 篇来源、21 个主题与 18 类方法**。其中 **3 篇原始研究已有 4 条结构化结果、8 个原文坐标**，覆盖 MEG、fMRI 和 TMS。这些坐标均保留原文未明确模板变体的 MNI 空间；来源核对由 AI 辅助完成，不代表人工认证。其余文献可继续补充结果。目录条目数与实际图谱标签数是不同概念。

## 空间与证据

脑内主参考为 **FSL MNI152NLin6Asym**。实际体积、表面、流线及论文坐标分别保留来源与空间说明。AAL / AAL3 的原生数据与项目估计配准的衍生版本分开提供，见 [AAL 接入说明](docs/AAL_INTEGRATION.md)。

- 对齐到同一参考的 ROI 才能计算共同网格上的重叠。标签 / 掩膜采用最近邻采样，连续图采用三线性采样后阈值化；重采样不执行新的解剖配准。
- 本地影像若空间未确认，可先通过 **ROI 对比 → 导入 → 查看原生影像** 独立查看。仅写“MNI”或存在有效仿射，不足以确认与主模板一致。
- 书目元数据、文献摘要、结构化结果与来源坐标分别管理。在线导入元数据不会生成结论或坐标；宏观脑区标签和图像点击使用明确记录的区域关联。

## 保存与共享

无需账号。批注、论文修改和命名视图保存在当前浏览器；完整项目文件还包含视图状态、批注、本地证据及导入影像的可恢复数据。自定义影像跨设备使用需传递项目文件。

视图链接保存公开数据的相机、显示、切片、ROI 和筛选设置，不包含批注、自由检索文字、本地论文内容或影像文件。单独的证据 JSON 用于合并论文 / 结果记录，BibTeX 用于参考文献管理。详见[保存与分享](docs/USER_GUIDE.md#保存与分享)。

## 本地运行

安装 Node.js 后运行：

```sh
npm ci
npm run check
npm run build
npm run preview
```

打开终端显示的地址。开发使用 `npm run dev`；运行网页无需 Python。公开 GitHub Pages 包使用 `npm run build:public`，部署路径为 `/Brian-Learning/`。
