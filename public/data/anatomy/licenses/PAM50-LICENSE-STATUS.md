# PAM50 data-license status

The local anatomical surfaces were generated from the official PAM50 data at commit `609a18235d9143dad0d6bf5bb35e2bff9e55196f`:

- https://github.com/spinalcordtoolbox/PAM50/tree/609a18235d9143dad0d6bf5bb35e2bff9e55196f
- Official description: https://spinalcordtoolbox.com/en/latest/overview/concepts/pam50.html
- Citation: De Leener B, Fonov VS, Collins DL, Callot V, Stikov N, Cohen-Adad J. PAM50: Unbiased multimodal template of the brainstem and spinal cord aligned with the ICBM152 space. NeuroImage 165:170–179 (2018). https://doi.org/10.1016/j.neuroimage.2017.10.041
- Atlas citation: Levy S, Benhamou M, Naaman C, Rainville P, Callot V, Cohen-Adad J. White matter atlas of the human spinal cord with estimation of partial volume effect. NeuroImage 119:262–271 (2015).

As checked on 2026-10-25, the standalone PAM50 repository and pinned tree contain no separate LICENSE file and its README does not state a data-specific redistribution grant. The Spinal Cord Toolbox software license is not asserted here as a license for these atlas data. Public availability and a scientific citation alone are not treated as redistribution authorization.

**No data redistribution license is asserted by this project.** Public release packaging excludes the downloaded PAM50 NIfTI files and precomputed PAM50 mesh derivatives. Any optional browser access goes directly to the original official source on the user's request, and generates temporary local display geometry; no source data or generated PAM50 geometry is rehosted by the public site. This delivery arrangement does not create a data license or authorize users to redistribute their own derivatives.

The original source files and local derivatives remain available in the private working copy. Further public redistribution requires a suitable explicit upstream grant.
